# Zumi

Cachorro caramelo virtual para o ESP32 CYD clássico. Este repositório é o case de produto e a base de engenharia: o que o Zumi é, como uma feature vira PRD, e onde o código mora.

O firmware em `firmware/` é a estrutura. A regra de jogo ainda não foi especificada num PRD aprovado.
