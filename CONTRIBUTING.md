# Como contribuir

1. Leia [docs/product/README.md](docs/product/README.md) e [docs/engineering/workflow.md](docs/engineering/workflow.md).
2. Feature nova: PRD aprovado em `docs/product/prds/` antes do código. Se a entrega muda página pública, preencha [docs/product/product-seo.md](docs/product/product-seo.md).
3. Atualize a `main`, crie a branch, implemente nas camadas de [docs/engineering/architecture.md](docs/engineering/architecture.md).
4. Atualize a branch com a `main` de novo, resolva conflitos e abra o pull request.
